How legal downloads work

Wikimedia Commons results may use public-domain, CC BY, CC BY-SA, or other license conditions. The application displays provider metadata. Check the original file page and any model/property restrictions before reuse. A download button only appears when a recognized, permitted license is indicated; if a browser blocks downloading, the source page can be opened manually.

News, YouTube, TikTok, Instagram, Google and Pexels buttons open external searches for discovery only. They do not grant reuse rights. Obtain permission or use authorized APIs/licenses for those clips.

Storage & privacy

Projects are saved in your browser's local storage. Clearing browser data may remove them. Export JSON regularly. No backend account or uploaded transcript server is used.
